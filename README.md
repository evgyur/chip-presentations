## Как открыть

Скачайте HTML-файл презентации и откройте его в браузере. Все изображения, шрифты, стили и скрипты встроены; интернет для просмотра не требуется. Страница файла на GitHub показывает исходный код, а не запускает презентацию.

[Скачать текущую презентацию](https://raw.githubusercontent.com/evgyur/chip-presentations/main/presentations/2026-11-18-personal-hedge-fund/index.html)

### Управление

- `←` / `→` или кнопки внизу — переключение слайдов.
- Метка **H2.0** на слайде: наведите указатель, чтобы открыть тезисы докладчика; нажмите, чтобы закрепить окно. На телефоне — касание.
- `N` — открыть или закрепить тезисы; `Esc` — закрыть.
- Кнопка полного экрана — в верхней панели.

## О текущей презентации

Шесть функций инвестиционной команды внутри одного личного ИИ-агента: информация, анализ, исследование стратегий, риск, исполнение и управление капиталом. Включены тезисы докладчика и ретроспективные примеры с указанием их статуса.

Это рабочая версия выступления, а не подтверждение боевой готовности всех упомянутых интеграций. Пример HYPE — ретроспективная реконструкция на реальных данных, не заявление об исполненной сделке.

## Структура

Каждая презентация хранится в своей папке `presentations/YYYY-MM-DD-short-title/`. Основной файл — `index.html`.

В репозиторий не включены приватные переписки, внутренний handoff, учётные данные и служебные материалы подготовки.
